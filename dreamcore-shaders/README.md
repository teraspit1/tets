# DreamCore Shader Draft (for Minecraft Java)

Ниже — минимальный шейдер-пак с вайбом DreamCore: мягкие пастельные цвета, лёгкая хроматическая аберрация, виньетка, пульсирующий tint и плёночный шум.

## Совместимость

- Текущая «Minecraft 26.1» официально не существует (в Java-ветке актуальны версии вида `1.xx.x`).
- Этот код написан в GLSL `#version 150`, обычно подходит для Iris/OptiFine на современных версиях Java Edition.

## Установка

1. Скопируй папку `dreamcore-shaders` в директорию shaderpacks.
2. Установи Iris (или OptiFine).
3. В игре: `Настройки → Видео → Шейдеры` и выбери пакет.

## Что можно крутить

- В `gbuffers_basic.fsh`: насыщенность (`hsv.y *= 0.78`) и силу розово-голубого tint.
- В `final.fsh`: силу хроматической аберрации (`ca`), зерна (`noise * 0.03`) и блюма (`mix(..., 0.18)`).
